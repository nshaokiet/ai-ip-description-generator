# Docs / Tài liệu dự án

Thư mục này là nơi quản lý tài liệu kỹ thuật và governance của dự án.

## Nhiệm vụ / Responsibilities

| Folder / Thư mục | English role | Vai trò tiếng Việt |
|---|---|---|
| `decisions/` | Architecture Decision Records | Quyết định kiến trúc và quyết định kỹ thuật đã được phê duyệt |
| `tasks/` | Task specifications | Đặc tả nhiệm vụ, acceptance criteria và phạm vi triển khai |
| `operations/` | Project operations | Điều phối dự án, review log, control center và autonomous-agent protocol |
| `archive/` | Historical archive | Lưu snapshot/tài liệu cũ để truy vết, không dùng làm canonical source hiện hành |

Các file chính ở cấp `docs/`:

- `system-specification.md` — System Specification / Đặc tả hệ thống.
- `architecture.md` — Architecture Notes / Ghi chú kiến trúc.
- `workflow.md` — Workflow / Quy trình làm việc.

GitHub là Technical Source of Truth. Tài liệu trong `archive/` không được dùng để ghi đè tài liệu canonical hiện hành.
