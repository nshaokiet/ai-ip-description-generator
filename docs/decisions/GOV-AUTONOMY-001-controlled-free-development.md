## 1. Problem and proposed decision

Current AGENTS §8.1 requires each task ID/scope to have explicit Human authorization.
The Owner requests autonomy for free product work while retaining review, security,
cost and production controls. This proposal lets Codex derive a **small task** from
the Owner-approved product scope/roadmap, record its ID/AC/authorization reference,
then implement/test/remediate/open PR and merge only when every gate below passes.
It does not authorize an arbitrary backlog, architectural rewrite or paid service.
